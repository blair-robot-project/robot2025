# Lobster AdvantageScope Model
The model of the 2025 robot lobster for AdvantageScope
## Instalation
1. Open AdvantageScope
2. Open the Assets folder `Help / Open Assets Folder`
3. Copy this folder into the Assets folder
## Models
* `model.glb`: The base of the robot
* `model_0.glb`: The manipulator of the robot
* `model_1.glb`: The elevator of the robot
* `model_2.glb`: The climb of the robot
